# АМТ Сервис · Premium Brand Redesign 3.0

Локальная демонстрационная концепция сайта сервисного центра в Санкт-Петербурге.

## Запуск

Откройте `index.html` в современном браузере. Для страницы и формы достаточно локальных файлов. Интернет нужен для перехода в Telegram и Яндекс Карты.

Форма собирает текст из выбранных вариантов и введённых деталей. На последнем шаге скопируйте его, откройте контакт сервиса и отправьте сообщение в Telegram. При ограничениях браузера форма выделяет текст для ручного копирования.

## Логотип и палитра

Файлы `assets/amt-logo.png` и `assets/amt-logo-dark.png` подготовлены из приложенного изображения. У исходника непрозрачный чёрный фон. Поля обрезаны, фон восстановлен как прозрачный, а для подвала осветлена только текстовая часть. Знак и надпись показаны в размере 146 × 36 px без растягивания. Для более чёткого изображения на экранах высокой плотности нужен исходный SVG или PNG большего разрешения.

Доминирующий оранжевый в исходном растре близок к `#B24502`. Для интерфейса выбрана более яркая версия того же оттенка `#F86100` с тёмным текстом на кнопках. Для типографики используется системный Segoe UI с поддержкой кириллицы, если Manrope не установлен на устройстве. Схема смартфона условная и поддерживает переключение между сближёнными и разнесёнными слоями.

## Фотографии

В проекте предусмотрена галерея с увеличением снимков. Сейчас блок о мастерской ведёт к фотографиям в карточке сервиса. Для подключения галереи нужны оригиналы или разрешение правообладателей. Плитки появляются по мере добавления снимков.

| Ключ | Файл в `assets/photos/` | Кадр |
| --- | --- | --- |
| `hero` | `hero.webp` | Вывеска или общий вид мастерской, желательно горизонтальный кадр |
| `entrance` | `entrance.webp` | Вход с вывеской |
| `interior` | `interior.webp` | Общий вид помещения |
| `workbench` | `workbench.webp` | Рабочее место мастера |
| `phone-repair` | `phone-repair.webp` | Ремонт телефона |
| `computer-repair` | `computer-repair.webp` | Ремонт ноутбука или компьютера |
| `equipment` | `equipment.webp` | Инструменты или техника крупным планом |

Сохраните одобренные фотографии в `assets/photos/`, затем внесите их имена в объект `photos` в `script.js`. Например, `entrance: { file: 'entrance.webp' }`. Для двух размеров укажите `file` для изображения шириной 1280 пикселей и `small` для файла шириной 640 пикселей. Кадрирование превью можно настроить через `object-position` в CSS. На странице превью открываются в полноразмерном просмотре с кнопками навигации, стрелками клавиатуры и закрытием по Escape.

## Перед публикацией

Согласуйте с владельцем размещение демонстрационной концепции с названием и логотипом компании. Перед добавлением фотографий получите разрешение на их публикацию. Пометка о демонстрационной концепции размещена на первом экране и в подвале. Метатег `noindex, nofollow` просит поисковики не индексировать страницу, но не ограничивает доступ по ссылке.

## GitHub Pages

1. Добавьте папку проекта как существующий локальный репозиторий в GitHub Desktop.
2. Когда будете готовы, опубликуйте репозиторий под именем `amt-service-demo`.
3. В настройках репозитория выберите **Pages → Deploy from a branch → main → /(root)**.
4. После развёртывания откройте URL из настроек Pages и проверьте переходы к форме и контактам.

`index.html` находится в корне, а CSS, JavaScript и изображения подключаются относительными путями. Файл `.nojekyll` отключает обработку Jekyll. Для развёртывания не требуется установка зависимостей или сборка проекта.
